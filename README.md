# GTNH Large Turbine Calculator

Web calculator for Large and XL Turbo turbines from **GregTech: New Horizons** (GT5-Unofficial).

![GTNH](https://img.shields.io/badge/GTNH-2.7_/_2.9-orange)

## Usage

Open in browser — no install required:
**https://eldrinn-elantey.github.io/GTNH-Large-Turbine-Calculator/**

## Features

### Calculator

Two sub-tabs — **Large Turbines** and **XL Turbo Turbines** — each with:

- Shared settings: rotor tier filter, material (136 rotors), blade size (Small / Normal / Large / Huge), dynamo hatch tier
- Three cards side by side: **Steam**, **Gas**, **Plasma**
- Per-card: Tight/Loose mode, fuel selector, Optimal/Manual flow
- Results: optimal flow, output EU/t, dynamo hatch count, effective flow/output, rotor lifetime
- Multi-card comparison (add/remove slots)

### EHE Planner

- **Plasma EHE** — input recipe parameters, get EHE count, SC steam output, turbine count and power
- **Non-XL EHE** — input hot fluid flow, get SC/SH steam split and turbine count

### Steam Gen

Reference table for Large Heat Exchanger, Whakawhiti Wera XL, and Thermal Boiler.

### Fuels

Searchable reference tables: Steam, Gas (28 fuels), Plasma (128 fuels).

### Rotors

136 rotors — filterable by blade size, sortable by any column.

### Compare Rotors

Side-by-side sortable comparison of all rotors for a chosen fuel and mode.

## Data sources

Rotor stats and turbine formulas verified against GT5-Unofficial source and cross-checked with community Excel sheets. Supports GTNH 2.7 and 2.9 data sets.
